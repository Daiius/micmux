## 目的

SSH 接続元の物理マイクを、接続先の仮想マイクとして使えるようにする。

> On-demand microphone forwarding over SSH, independent of terminals and applications.

SSH 先で動かしているコーディングエージェント（Claude Code など）の**標準の音声入力**を、手元のマイクで使うためのもの。
主眼は次の 3 つ:

1. **接続先のアプリを改造しない** — 接続先には「普通の録音デバイス」として見える仮想マイクを置く。
   アプリは自分がリモートにいることを知らなくてよい。
2. **必要なときだけマイクを開く** — 接続先でアプリが録音を始めたことを検出し、そのあいだだけ接続元のマイクを起動する。
   待機中はマイクを開かず、音声も送らない。
3. **既存の SSH + tmux の使い方を変えない** — 音声は端末の入出力とは別の経路で送る。ターミナルエミュレーターにも
   tmux にも依存しない。認証と暗号化は OpenSSH に任せる。

## スコープ

- **実装済み**: 仮想マイクの生成と後片付け / 録音要求の検出 / オンデマンドのマイク起動と PCM 転送 /
  録音許可（armed / disarmed）と連続録音時間の上限 / `ssh` に連動した自動起動（`LocalCommand`・`Match exec`）/
  SSH の多重化への相乗り（認証 1 回）/ 操作用ソケット（`arm`・`disarm`・`toggle`・`status`）/
  接続先・接続元の点検（`doctor`・`debug`）/ 接続先の音声基盤のセットアップスクリプト。
- **実機で確認済みの組み合わせ**: 接続元 macOS（Apple シリコン・内蔵マイク）→ 接続先 Debian 13（PulseAudio 17.0）→
  Claude Code の音声入力。詳細は [07](./07-roadmap.md)。
- **計画中**: 録音要求を断ったときの通知 / 自動再接続 / 許可条件の自動判定（ターミナルが最前面のときだけ、など）。
  詳細は [07](./07-roadmap.md)。
- **スコープ外**: スピーカー出力の転送 / 双方向の通話 / 独自の音声認識 / 独自の SSH 実装 / カーネルドライバ /
  接続先のアプリの改造 / 高音質の音楽転送 / GUI / 複数の接続元の音声のミキシング。

## アーキ概観

```
接続元 (macOS)                              接続先 (Debian)
┌────────────────────────┐    SSH     ┌──────────────────────────────────────┐
│ マイク → micmux connect  ├───────────┤ micmux bridge → 仮想マイク → アプリ     │
│        (client)        │ 標準入出力  │                (PulseAudio の null sink) │
└────────────────────────┘            └──────────────────────────────────────┘
          ← START / STOP（録音要求。bridge が録音ストリームの有無から導く）
          → PCM（armed のときだけ。s16le モノラル）
```

- **単一の Rust バイナリ**。接続元では `micmux connect`、接続先では `micmux bridge` として動く。
  依存は `libc` と、マイク取得用の `cpal`（macOS では常に、Linux では `native` feature で）だけ。
- **通信路は SSH の標準入出力**。接続元が `ssh <host> -- micmux bridge` を子プロセスとして起動し、そのパイプに
  独自のフレームを流す。待ち受けポートもリバースフォワーディングも使わない（[02](./02-architecture.md) §2）。
- **接続先の音声基盤は PulseAudio 互換**。bridge は `pactl` / `pacat` を子プロセスとして使い、libpulse には
  リンクしない（[04](./04-audio.md) §1）。
- **設計の柱**: **録音するかどうかを決めるのは常に接続元**。接続先からの START は要求でしかない
  （[05](./05-security.md) §1）。

## 公開リポジトリでの秘匿方針

本リポジトリは**公開**であるため、PRD・README・issue・コミットメッセージに以下を持ち込まない:

- 秘密情報（鍵・トークン・パスフレーズ）。
- 利用者の環境を特定する情報（ホスト名・ユーザー名・IP アドレス・ホームディレクトリや一時ディレクトリの実パス）。
  例示には `dev-server` を使う。
- `micmux debug` の出力はホスト名やユーザー名を含む。貼り付けたものをそのまま文書に写さない。
